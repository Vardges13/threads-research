# ИИ-тренды для контента

**Цель:** Еженедельный мониторинг ИИ-новостей для создания вирусного контента

## Источники данных
- **HackerNews** — основной источник горячих ИИ-дискуссий
- **GitHub Trending** — новые ИИ-проекты
- **Reddit AI** — community insights
- **Twitter/X ИИ-экспертов** — оперативные новости

## Критерии отбора
- **Вирусный потенциал** (страхи, споры, прорывы)
- **Практическая ценность** для предпринимателей
- **Актуальность** (не старше 48 часов)
- **Социальная реакция** (комменты, репосты)
