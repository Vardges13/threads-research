# 🎯 Vibe Kanban - Канбан-доска для ИИ-агентов

Визуальная канбан-доска для оркестрации параллельных ИИ-кодинг-агентов. Вдохновлено [vibekanban.com](https://vibekanban.com) от BloopAI.

## 🚀 Быстрый старт

1. **Открыть в браузере:**
   ```bash
   open /Users/bond/.openclaw/workspace/skills/vibe-kanban/index.html
   ```

2. **Или через OpenClaw Canvas:**
   ```bash
   openclaw canvas present skills/vibe-kanban/index.html
   ```

3. **Добавить задачу** — заполните форму вверху страницы
4. **Перетащите** задачи между колонками (Plan → Coding → Review → Done)
5. **Dispatch** задачи кодинг-агентам кнопкой 🚀

## 📋 Функционал

### ✨ Колонки канбана
- 📝 **План** — новые задачи для планирования
- 🤖 **Кодинг** — задачи в разработке
- 👁️ **Ревью** — код на проверке
- ✅ **Готово** — завершённые задачи

### 🎮 Возможности
- ➕ **Добавление задач** с названием, описанием, приоритетом
- 🎯 **Назначение агентов** (Claude Code, Cursor, Copilot, Custom)
- 🏷️ **Цветовая кодировка** приоритетов (🔴 High, 🟡 Medium, 🟢 Low)
- ⏱️ **Таймеры** — время работы над задачей
- 🚀 **Dispatch** — отправка задач агентам
- ✅ **Approve** — одобрение в ревью
- 📊 **Статистика** — всего, в работе, завершено, среднее время
- 💾 **localStorage** — автосохранение состояния
- 📱 **Адаптивный дизайн** — работает на мобильных

### 🎨 Дизайн
- 🎨 Современный минималистичный стиль
- 🌅 Светлая тема (как Linear/Notion)
- 🔤 Шрифт Inter (Google Fonts)
- 🎭 Иконки-эмодзи
- 💫 Плавные анимации и переходы
- 🌐 Русский интерфейс

## 📜 Скрипт dispatch.sh

Скрипт для интеграции с кодинг-агентами:

```bash
./scripts/dispatch.sh '{"title":"API задача","agent":"Claude Code","description":"Создать REST API"}'
```

**Что делает:**
- 📥 Принимает JSON с данными задачи
- 🔍 Анализирует агента и формирует команду
- 📋 Выводит готовую команду для выполнения
- 📝 Логирует все операции в `logs/dispatch.log`

## 🎯 Использование

### Добавление задач
1. Введите название задачи
2. Добавьте описание (опционально)
3. Выберите приоритет и агента
4. Нажмите "➕ Добавить задачу"

### Workflow
1. **📝 План** — планируйте задачи
2. **🚀 Dispatch** — отправьте агенту (переходит в Coding)
3. **👁️ Review** — перетащите для ревью
4. **✅ Approve** — одобрите результат (переходит в Done)

### Drag & Drop
- Перетаскивайте карточки между колонками
- Автоматически обновляются временные метки
- Счётчики колонок обновляются в реальном времени

## 📊 Горячие клавиши
